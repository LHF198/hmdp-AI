# 黑马点评（hmdp）需求文档

> 版本：v1.0 ｜ 更新日期：2026-08-12 ｜ 状态：功能基本完成，部分增强待迭代
> 文档范围：完整记录系统已实现功能与未实现/待完善功能，作为开发、测试与后续迭代的依据。

---

## 1. 项目概述

**黑马点评**是一个基于 Spring Boot + Vue 3 的本地生活服务点评平台，覆盖用户系统、商铺查询、内容分享（笔记）、关注社交、优惠券秒杀等核心业务场景，并集成了 AI 探店助手（智能问答 + RAG 知识库 + 业务工具调用）。

### 1.1 项目定位

- 面向大众用户的本地生活消费决策平台（对标大众点评）
- 技术教学与实战项目：重点演示 Redis 在缓存、分布式锁、GEO、BitMap、Stream、ZSet 等场景下的应用
- 同时作为 Spring AI（ChatClient / RAG / 会话记忆 / Function Calling）的集成示范

### 1.2 技术栈

| 层次 | 技术 | 说明 |
|------|------|------|
| 后端框架 | Spring Boot 3.4.5（JDK 17） | REST API，端口 8081 |
| 数据库 | MySQL 5.7+ / 8.0 + MyBatis-Plus 3.5.9 | 持久化存储与 ORM |
| 缓存 | Redis + Lettuce + Redisson 3.27.2 | 缓存 / 分布式锁 / GEO / BitMap / Stream / ZSet / Set |
| AI | Spring AI 1.0.0（DashScope 兼容 OpenAI 协议） | 问答 / RAG / 记忆 / 工具调用 |
| 前端 | Vue 3 + Vite 6 + Element Plus + Pinia | SPA，nginx 静态部署（8080）并反代 `/api` |
| 工具 | Hutool、Lombok、Lua | 通用工具、代码简化、原子脚本 |

### 1.3 部署架构

```
浏览器 → nginx(8080) ──静态资源 /  SPA ──┐
            └── /api 反向代理 ────────→ Spring Boot(8081)
                                            ├── MySQL(3306) hmdp 库
                                            ├── Redis(6379)
                                            └── DashScope 大模型 API（可选，无 Key 降级）
```

## 4. 非功能需求

### 4.1 性能与并发

| 项目 | 说明 | 状态 |
|------|------|------|
| 缓存穿透防护 | 空值缓存方案已封装（CacheClient），商铺查询当前用互斥锁方案 | ✅ |
| 缓存击穿防护 | 互斥锁（当前默认）；逻辑过期方案已封装可切换 | ✅ |
| 缓存雪崩防护 | 商铺缓存 TTL 随机化（CacheClient） | ✅ |
| 秒杀防超卖 | Lua 原子扣减 + DB 条件更新（stock > 0）+ 分布式锁 | ✅ |
| 秒杀一人一单 | Lua Set 预校验 + DB 复查（事务内） | ✅ |
| 秒杀接口吞吐 | 校验与落库解耦，异步消费，下单接口不落库 | ✅ |
| Feed 推送性能 | 异步线程池推送，不阻塞发布接口 | ✅ |
| N+1 查询 | 点赞 Top5、订单列表均批量查询 | ✅ |
| 消息消费可靠性 | pending 重试 + 死信队列 | ✅ |
| JVM 退出 | 所有业务线程池 daemon 化 + @PreDestroy 优雅关闭 | ✅ |

| 项目 | 说明 | 状态 |

| 登录鉴权 | 双拦截器（刷新 + 登录校验），写操作强制登录 | ✅ |
| 越权防护 | 删笔记/删评论/改资料/支付均校验本人归属 | ✅ |
| SQL 注入 | 排序字段白名单、MyBatis-Plus 参数化 | ✅ |

### 4.3 可用性与可运维

- 未配置 AI Key 应用可正常降级启动
- Redis 不可用时：AI 限流自动放行、GEO 查询回退 DB
- Redis 重启后：Stream 消费者组自动重建、店铺 GEO 启动时自动重建
- 多环境配置：dev（本机开箱即用）/ prod（全环境变量注入）
- 向量库快照持久化：重启免重新向量化，省 embedding 配额

## 6. 缓存与 Redis 设计要点（速查）

| Redis 结构 | Key 规则 | 用途 |
|-----------|----------|------|
| String | `login:code:{phone}` | 短信验证码（2min） |
| Hash | `login:token:{token}` | 登录会话（25 天滑动续期） |
| String | `cache:shop:{shopId}` | 店铺缓存（30min） |
| String | `cache:type` | 店铺类型缓存（24h） |
| BitMap | `sign:{userId}:{yyyyMM}` | 每日签到 |
| GEO | `shop:geo:{typeId}` | 附近店铺搜索 |
| ZSet | `blog:liked:{blogId}` | 笔记点赞 Top-N（score=时间戳） |
| ZSet | `feed:{userId}` | 关注流收件箱（score=时间戳） |
| Set | `follows:{userId}` | 关注集合 / 共同关注交集 |
| String | `seckill:stock:{voucherId}` | 秒杀库存 |
| Set | `seckill:order:{voucherId}` | 秒杀已下单用户 |
| String | `seckill:begin/end:{voucherId}` | 秒杀时间窗（毫秒时间戳） |
| Stream | `stream.orders` / `stream.orders.dlq` | 秒杀订单消息队列 / 死信队列 |
| String | `ai:chat:memory:{conversationId}` | AI 会话记忆（TTL 1 天） |
| String | `ai:rate:{yyyyMMddHHmm}:{ip}` | AI 接口限流计数 |

## 7. 验收标准摘要

1. 未登录用户可浏览首页/店铺/笔记/评论/地图/AI 助手；点击需登录的操作跳转登录页并可回跳
2. 手机号验证码登录全流程可用（验证码从接口响应获取）
3. 秒杀场景：同用户重复下单被拒、库存扣完提示"库存不足"、超卖不发生
4. 关注流滚动分页无重复/无遗漏（相同时间戳笔记通过 offset 处理）
5. 删除笔记后评论、点赞数、Feed、图片均同步清理
6. 修改昵称/头像后 `/user/me` 与 Redis 会话立即生效
7. 未配置 AI_API_KEY 时应用可启动，AI 接口返回友好提示而非 500
8. 重启应用后 Stream 消费者组、GEO 缓存自动重建
