# 黑马点评（hmdp）接口文档

> 版本：v1.1 ｜ 更新日期：2026-08-14 ｜ 适用后端：Spring Boot 3.5.16（端口 8081）
> 前端经 nginx 反代访问：`/api` → 后端 8081（如 `GET http://localhost:8080/api/shop/1`）

---

## 1. 通用约定

### 1.1 Base URL

- 直连后端：`http://localhost:8081`
- 经 nginx 前端网关：`http://localhost:8080/api`

### 1.2 认证方式

- 登录成功后接口返回 **token 字符串**，前端保存于 `sessionStorage`，后续请求在请求头携带：

```
authorization: <token>
```

- 未携带或 token 失效 → HTTP **401**，前端自动跳转登录页。
- 鉴权策略：**默认拒绝 + 显式放行**——Controller 方法/类标注 `@Anonymous` 方可匿名访问（如 `/shop/**`、`/voucher/list/**`、`/shop-type/**`、`/blog/hot`、`/blog/{id}`、`/blog/likes/{id}`、`/blog-comments/{blogId}`、`/user/code`、`/user/login`、`/api/ai/**` 等），其余接口一律需登录。

### 1.3 统一响应结构

所有业务接口（AI 模块除外）返回 `Result`：

```json
// 成功
{ "success": true, "errorMsg": null, "data": { ... }, "total": null }
// 失败（HTTP 200，业务层面失败）
{ "success": false, "errorMsg": "库存不足", "data": null, "total": null }
```

| 字段 | 类型 | 说明 |
|------|------|------|
| success | Boolean | 是否成功 |
| errorMsg | String | 失败原因（成功为 null） |
| data | Object | 业务数据 |
| total | Long | 分页总数（仅部分接口使用） |

### 1.4 HTTP 状态码

| 状态码 | 含义 |
|--------|------|
| 200 | 成功（业务失败也返回 200，以 success=false 区分） |
| 400 | 参数错误（@Valid 校验失败） |
| 401 | 未登录 / token 失效 |
| 429 | AI 接口限流 |
| 500 | 服务器内部错误 |

## 2. 用户模块 `/user`

### 2.1 发送验证码

- **POST** `/user/code?phone=13800138000`
- 说明：校验手机号格式，生成 6 位验证码存 Redis（`login:code:{phone}`，TTL 2 分钟）。**演示环境无短信通道，验证码直接在响应中回显**。
- 响应示例：

```json
{ "success": true, "errorMsg": null, "data": "123456", "total": null }
```

### 2.2 登录（验证码 / 密码，二选一）

- **POST** `/user/login`
- 说明：
  - **验证码登录**：校验 Redis 验证码（一次性使用，防复用），用户不存在则自动注册；
  - **密码登录**：账号须已设置密码（「我的-修改密码」设置），校验密码（MD5+盐）；连续失败 5 次锁定 10 分钟（`login:fail:{phone}`），防暴力破解；
  - 验证码与密码都不传 → 提示"请输入验证码或密码"。
- 请求体：

```json
{ "phone": "13800138000", "code": "123456", "password": null }
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| phone | String | 是 | 手机号，正则校验 |
| code | String | 否 | 验证码（与 password 二选一） |
| password | String | 否 | 登录密码（与 code 二选一） |

- 响应示例（data 为 token）：

```json
{ "success": true, "errorMsg": null, "data": "a1b2c3d4...", "total": null }
```

### 2.3 设置/修改密码

- **PUT** `/user/password`（需认证）
- 说明：未设置过密码时无需原密码；已有密码时必须校验原密码。新密码格式：4~32 位字母、数字或下划线（`^\w{4,32}$`）。
- 请求体：

```json
{ "oldPassword": "old-pass", "newPassword": "new-pass" }
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| oldPassword | String | 否 | 原密码（账号已设置密码时必填） |
| newPassword | String | 是 | 新密码（4~32 位字母、数字或下划线） |

### 2.4 退出登录

- **POST** `/user/logout`（需认证）
- 说明：删除 Redis 中 `login:token:{token}`，立即失效。

### 2.5 获取当前登录用户

- **GET** `/user/me`（需认证）
- 响应 data 示例：

```json
{ "id": 1, "nickName": "用户_abc123", "icon": "/imgs/avatar/1.png" }
```

### 2.6 查询用户详情（隐私字段）

- **GET** `/user/info/{id}`（需认证）
- 说明：返回 UserInfo（城市/介绍/性别/生日/粉丝数等），无记录时 data 为 null。

### 2.7 按 ID 查询用户（公开）

- **GET** `/user/{id}`
- 响应 data：UserDTO（id / nickName / icon）。

### 2.8 修改个人资料

- **PUT** `/user/info`（需认证）
- 说明：强制绑定当前登录用户，禁止越权；昵称/头像同步更新 Redis 登录态；粉丝/关注/积分/等级字段不可通过此接口修改。
- 请求体：

```json
{ "nickName": "新昵称", "icon": "/imgs/avatar/x.png", "city": "杭州", "introduce": "你好", "gender": true, "birthday": "2000-01-01" }
```

### 2.9 每日签到

- **POST** `/user/sign`（需认证）
- 说明：Redis BitMap `sign:{userId}:{yyyyMM}` 置位当天。

### 2.10 签到统计（连续天数）

- **GET** `/user/sign/count`（需认证）
- 响应 data：当月截止今天的连续签到天数（整数）。

## 3. 商铺模块 `/shop`、`/shop-type`

### 3.1 查询商铺详情

- **GET** `/shop/{id}`（公开）
- 说明：带缓存（互斥锁防击穿，TTL 30 分钟）；不存在时 success=false。
- 响应 data 示例：

```json
{
  "id": 1, "name": "103茶餐厅", "city": "杭州", "typeId": 1,
  "images": "/imgs/shop/1.png", "area": "大关", "address": "...",
  "x": 120.15, "y": 30.28, "avgPrice": 80, "sold": 4215,
  "comments": 500, "score": 47, "openHours": "10:00-22:00"
}
```

### 3.2 新增商铺

- **POST** `/shop`（需认证）
- 请求体：Shop 实体（name 必填等）
- 响应 data：商铺 id。

### 3.3 更新商铺

- **PUT** `/shop`（需认证）
- 说明：更新 DB 后删除缓存（失败重试 3 次），坐标变更同步更新 GEO。

### 3.4 按类型分页查询商铺

- **GET** `/shop/of/type`（公开）

| 参数 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| typeId | Integer | 是 | - | 商铺类型 id |
| current | Integer | 否 | 1 | 页码 |
| x / y | Double | 否 | - | 经纬度，传入时按 5km 内距离排序 |
| city | String | 否 | - | 城市过滤 |
| sortBy | String | 否 | - | `comments`（人气）/ `score`（评分），传入时走 DB 排序 |
| isAsc | Boolean | 否 | true | 是否升序（GEO 时距离升序，isAsc=false 反转） |

- 说明：GEO 数据缺失时自动回退数据库分页查询。
- 响应 data：Shop 列表（GEO 模式下含 `distance` 字段，单位米）。

### 3.5 按名称模糊搜索

- **GET** `/shop/of/name?name=茶&current=1&city=杭州&sortBy=comments&isAsc=false`
- 说明：sortBy 仅允许 `comments` / `score` 白名单，防止 SQL 注入。

### 3.6 城市列表

- **GET** `/shop/cities`
- 说明：常用城市保底（杭州/上海/北京/广州/深圳/成都/南京/武汉）+ 店铺数据去重并集。
- 响应 data：`["杭州", "上海", ...]`

### 3.7 地图模式全量店铺

- **GET** `/shop/map/list`
- 说明：返回全部店铺的 id/name/typeId/city/area/address/x/y/avgPrice/sold/comments/score。

### 3.8 商铺类型列表

- **GET** `/shop-type/list`（公开，Redis 缓存 24h）
- 响应 data 示例：

```json
[ { "id": 1, "name": "美食", "icon": "/imgs/type/1.png", "sort": 1 } ]
```

## 4. 笔记模块 `/blog`

### 4.1 发布笔记

- **POST** `/blog`（需认证）
- 请求体（Blog）：

```json
{
  "shopId": 1, "title": "探店笔记", "images": "/imgs/blogs/0/1/xxx.jpg,/imgs/blogs/0/1/yyy.jpg",
  "content": "环境很好..."
}
```

- 说明：发布后异步推送笔记 id 到所有粉丝的 Feed 收件箱（ZSet）。
- 响应 data：笔记 id。

### 4.2 笔记详情

- **GET** `/blog/{id}`（公开）
- 说明：附带作者 `name` / `icon`；登录状态下附带 `isLike`。

### 4.3 点赞 / 取消点赞

- **PUT** `/blog/like/{id}`（需认证）
- 说明：ZSet 记录点赞（score=时间戳）并维护 DB 计数，Redis 失败自动回滚 DB。

### 4.4 笔记点赞 Top-N

- **GET** `/blog/likes/{id}`（公开）
- 说明：返回点赞前 5 名用户列表（按点赞时间倒序）：`[{ "id": 1, "nickName": "...", "icon": "..." }]`

### 4.5 热门笔记

- **GET** `/blog/hot?current=1`（公开）
- 说明：按点赞数倒序分页，每页 5 条（MAX_PAGE_SIZE），附带作者与 isLike。

### 4.6 我的笔记

- **GET** `/blog/of/me?current=1`（需认证）

### 4.7 指定用户的笔记

- **GET** `/blog/of/user?id=1&current=1`（公开）

### 4.8 关注流（滚动分页）

- **GET** `/blog/of/follow?lastId=1730000000000&offset=0`（需认证）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| lastId | Long | 是 | 上一次返回的 minTime（时间戳），首屏传当前时间戳 |
| offset | Integer | 否 | 与 minTime 同分的记录偏移量，防重复 |

- 响应 data（ScrollResult）：

```json
{
  "list": [ { "id": 1, "title": "...", "name": "...", "icon": "...", "isLike": false } ],
  "minTime": 1730000000000,
  "offset": 1
}
```

- 说明：每页 2 条，需按返回的 minTime/offset 继续滚动。

### 4.9 删除笔记

- **DELETE** `/blog/{id}`（需认证，仅作者）
- 说明：级联删除评论、点赞缓存、粉丝 Feed 记录、本地图片文件。

## 5. 评论模块 `/blog-comments`

### 5.1 分页查询笔记评论

- **GET** `/blog-comments/{blogId}?current=1`（公开）
- 说明：按时间倒序，每页 10 条。
- 响应 data：

```json
{
  "records": [
    { "id": 1, "userId": 1, "parentId": 0, "answerId": 0, "content": "不错", "createTime": "...", "userNickName": "昵称", "userIcon": "/imgs/..." }
  ],
  "total": 12
}
```

### 5.2 发布评论 / 回复

- **POST** `/blog-comments/{blogId}`（需认证）
- 请求体：

```json
{ "content": "评论内容", "parentId": 0, "answerId": 0 }
```

- 说明：一级评论 parentId=0；回复时携带被回复评论 id（parentId）与被回复人 id（answerId）。同步笔记评论数 +1。内容最多 255 字。
- 响应 data：评论 id。

### 5.3 删除评论

- **DELETE** `/blog-comments/{id}`（需认证，仅作者）
- 说明：级联删除其下全部回复，同步笔记评论数（GREATEST 防负数）。

### 5.4 我的评论列表

- **GET** `/blog-comments/of/me`（需认证）
- 说明：最近 50 条，含关联笔记标题/首图：

```json
[ { "id": 1, "content": "...", "createTime": "...", "blogId": 1, "blogTitle": "...", "blogImages": "..." } ]
```

## 8. 优惠券模块 `/voucher`

### 8.1 新增普通优惠券

- **POST** `/voucher`（需认证）
- 请求体（Voucher）：`shopId`、`title`、`subTitle`、`rules`、`payValue`（分）、`actualValue`（分）、`type`（0 普通 / 1 秒杀）。
- 响应 data：优惠券 id。

### 8.2 新增秒杀优惠券

- **POST** `/voucher/seckill`（需认证）
- 请求体：Voucher 基础字段 + `stock`（库存）、`beginTime`、`endTime`。
- 说明：同步初始化 Redis：`seckill:stock:{id}`、`seckill:order:{id}`（Set）、`seckill:begin/end:{id}`（毫秒时间戳）。
- 响应 data：优惠券 id。

### 8.3 查询商铺优惠券列表

- **GET** `/voucher/list/{shopId}`（公开）
- 说明：返回普通券 + 秒杀券（含 stock/beginTime/endTime 等）。

## 9. 秒杀订单模块 `/voucher-order`（均需认证）

### 9.1 秒杀下单

- **POST** `/voucher-order/seckill/{voucherId}`
- 说明：执行 Lua 脚本原子校验（时间窗 → 库存 → 一人一单）并扣库存、投递 Redis Stream，异步线程落库建单。
- 返回结果（success=true 时 data 为订单 id）：

| 场景 | 返回 |
|------|------|
| 成功 | `success=true, data=订单id` |
| 库存不足 | `success=false, errorMsg="库存不足"` |
| 重复下单 | `success=false, errorMsg="不能重复下单"` |
| 未开始 | `success=false, errorMsg="秒杀尚未开始"` |
| 已结束 | `success=false, errorMsg="秒杀已经结束"` |

### 9.2 我的秒杀订单列表

- **GET** `/voucher-order/list`
- 响应 data（OrderVO 列表，按下单时间倒序）：

```json
[
  { "id": 12345, "voucherId": 1, "voucherTitle": "10元代金券", "payValue": 1000, "status": 1, "createTime": "2026-08-12T10:00:00" }
]
```

- status：1 未支付 / 2 已支付 / 3 已核销 / 4 已取消 / 5 退款中 / 6 已退款

### 9.3 模拟支付

- **PUT** `/voucher-order/pay/{orderId}`
- 说明：校验本人 + 未支付状态（status=1）后置为已支付（2）；演示环境无真实支付通道。

## 11. AI 助手模块 `/api/ai`

> 统一前缀 `/api/ai`，经 nginx 反代时不剥离前缀；未配置 `AI_API_KEY` 时接口返回"未配置"提示而非报错。

### 11.1 非流式问答

- **POST** `/api/ai/chat`
- 请求体：

```json
{ "message": "推荐几家杭州美食店", "conversationId": "1730000000000" }
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| message | String | 是 | 提问内容，最多 2000 字 |
| conversationId | String | 否 | 会话 ID（8~64 位字母/数字/连字符），缺省自动生成 |

- 响应（非 Result 结构）：

```json
{ "conversationId": "1730000000000", "answer": "...", "timestamp": 1730000000000 }
```

### 11.2 流式问答（SSE）

- **POST** `/api/ai/chat/stream`，Content-Type: `text/event-stream`
- 请求体同 11.1；响应为 SSE 流，逐块输出文本。

### 11.3 流式问答（纯文本流，GET）

- **GET** `/api/ai/chat/stream?message=你好&conversationId=xxx`
- 响应 Content-Type: `text/html;charset=utf-8`，纯文本流式输出，兼容旧前端逐字渲染。

### 11.4 清空会话记忆

- **DELETE** `/api/ai/conversation/{conversationId}`
- 说明：删除 Redis 中 `ai:chat:memory:{conversationId}`。
- 响应：`{ "success": true, "conversationId": "xxx" }`

### 11.5 健康检查

- **GET** `/api/ai/health`
- 响应：`{ "status": "UP", "service": "hmdp-ai-assistant", "timestamp": 1730000000000 }`

### 11.6 限流说明

- 默认每 IP 每分钟 30 次（Redis 固定窗口），超限返回 HTTP 429 + `{"success":false,"errorMsg":"请求过于频繁，请稍后再试"}`。

## 12. 数据模型

### 12.1 User（tb_user）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 主键自增 |
| phone | String | 手机号（唯一） |
| password | String | 密码（MD5 + 随机盐加密存储，格式 "盐@摘要"；空串表示未设置） |
| nickName | String | 昵称 |
| icon | String | 头像 |
| createTime / updateTime | DateTime | 创建/更新时间 |

### 12.2 UserInfo（tb_user_info，主键 user_id）

| 字段 | 类型 | 说明 |
|------|------|------|
| userId | Long | 用户 id（INPUT） |
| city | String | 城市 |
| introduce | String | 个人介绍（≤128 字） |
| fans / followee | Integer | 粉丝数 / 关注数 |
| gender | Boolean | 性别（false 男 / true 女） |
| birthday | LocalDate | 生日 |
| credits / level | Integer/Boolean | 积分 / 会员级别 |

### 12.3 Shop（tb_shop）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 主键 |
| name / city / area / address | String | 名称 / 城市 / 商圈 / 地址 |
| typeId | Long | 商铺类型 id |
| images | String | 图片（逗号分隔） |
| x / y | Double | 经度 / 纬度 |
| avgPrice | Long | 均价（元） |
| sold / comments / score | Integer | 销量 / 评论数 / 评分（×10 存储） |
| openHours | String | 营业时间 |
| distance | Double | 非表字段，GEO 查询时返回距离（米） |

### 12.4 ShopType（tb_shop_type）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 主键 |
| name | String | 类型名称 |
| icon | String | 图标 |
| sort | Integer | 排序 |

### 12.5 Blog（tb_blog）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 主键 |
| shopId | Long | 关联商铺 |
| userId | Long | 作者 id |
| title / content | String | 标题 / 内容 |
| images | String | 图片（最多 9 张，逗号分隔） |
| liked / comments | Integer | 点赞数 / 评论数 |
